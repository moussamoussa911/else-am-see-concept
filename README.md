# Else am See – digital concept

An independent, multilingual concept site for Else am See. It combines an
editorial lakeside brand experience with a digital menu, a visual reservation
flow, a shared-table cart and an owner-facing POS integration story.

## Local

```bash
npm start
```

Open `http://localhost:4176`.

This is a non-binding design concept. Reservations and orders are demonstrated
locally and are not sent to the restaurant.
